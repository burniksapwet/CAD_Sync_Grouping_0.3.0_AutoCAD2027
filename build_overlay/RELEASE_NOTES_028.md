# Find and Replace Block 0.2.8

This is a focused layer-filter reset update on top of v0.2.7.

- The first time Find and Replace Block opens, the left selector defaults to **All Layers**.
- If the palette is closed and later opened again, the left selector resets to **All Layers** regardless of what was selected before closing.
- Re-invoking the command while the palette is already open does not forcibly reset the current layer choice.
- Document switches while the palette remains open do not count as closing/reopening.
- All Blocks, RENAMEBLOCKS integration, ToolPalettte targets, manual drawing selection, Scale, and Standard behavior are otherwise unchanged.
